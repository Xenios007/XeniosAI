# ARCH-021 Diagrams — Experience, Conversation & Frontend Architecture

This directory contains the normative visual companions for ARCH-021.

| Diagram | Purpose |
| --- | --- |
| `01-experience-landscape.mmd` | Shows actors, experience surfaces, platform mediation, and authoritative capabilities |
| `02-conversation-interaction-flow.mmd` | Shows a conversational request from input through clarification, tools, confirmation, and response |
| `03-frontend-composition.mmd` | Shows logical frontend layers and dependency direction |
| `04-human-handoff-and-feedback-loop.mmd` | Shows escalation, human resolution, feedback capture, and governed improvement candidacy |
| `05-experience-evolution.mmd` | Shows the maturity path from usable foundation to adaptive ecosystem |

Diagrams complement the written architecture and do not override it.

Mermaid source must remain portable, readable, and valid under strict parsing. Node labels avoid implementation-product names because ARCH-021 is technology neutral.
