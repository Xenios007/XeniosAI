# ARCH-023 Diagram Catalog

The diagrams in this directory are normative visual companions to ARCH-023 — Customer & Relationship Management.

| Diagram | Purpose |
| --- | --- |
| `01-customer-relationship-landscape.mmd` | Shows customer capabilities and authoritative neighboring domains |
| `02-customer-profile-lifecycle.mmd` | Shows profile and relationship lifecycle with correction and restriction paths |
| `03-customer-context-assembly.mmd` | Shows purpose-bound assembly of customer context for consumers |
| `04-consent-segmentation-and-engagement.mmd` | Shows policy revalidation from segmentation through engagement and outcomes |
| `05-customer-relationship-evolution.mmd` | Shows controlled capability maturity and enduring guardrails |

All sources use Mermaid syntax without Markdown fences so documentation and validation pipelines can render them directly.
