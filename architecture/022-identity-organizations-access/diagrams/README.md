# ARCH-022 Diagrams — Identity, Organizations & Access

This directory contains the normative visual companions for ARCH-022.

| Diagram | Purpose |
| --- | --- |
| `01-identity-access-landscape.mmd` | Shows identity classes, relationship context, enforcement, and protected capabilities |
| `02-identity-lifecycle.mmd` | Shows the canonical identity lifecycle from proposal through retirement |
| `03-access-decision-flow.mmd` | Shows authentication, context collection, policy evaluation, provider enforcement, and evidence |
| `04-delegated-and-privileged-access.mmd` | Shows request, approval, activation, monitored use, expiry, and review |
| `05-identity-access-evolution.mmd` | Shows identity maturity from governed foundation to federated zero-standing-privilege ecosystems |

Diagrams complement the written architecture and do not override it. Mermaid source remains technology neutral and must pass strict parsing.
