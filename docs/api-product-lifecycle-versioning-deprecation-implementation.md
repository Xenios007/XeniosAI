# ARCH-033-08 API Product Lifecycle, Versioning & Deprecation

Executable introduction, preview, general-availability, version-mapping, deprecation, retirement, exit, recovery, observability, and assurance safeguards.

Lifecycle metadata remains non-authoritative and traceable to provider and registered contract versions. Preview is explicitly bounded, deprecation stays discoverable, retirement is migration-gated, and exit revokes credentials and resolves data obligations.
