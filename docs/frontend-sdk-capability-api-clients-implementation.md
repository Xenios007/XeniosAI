# ARCH-032-03 Frontend SDK, Capability & API Clients

Executable typed-client, identity-context, capability-discovery, retry, streaming, error, contract-version, recovery, observability, and assurance safeguards.

Generated types and capability discovery never grant authority. Retries are bounded and idempotency-aware, streams are resumable and non-authoritative, and every client artifact remains traceable to registered contract versions.
