# ARCH-037-01 Testing, Simulation & Conformance Overview

Executable quality-model, test-layer, evidence, risk-model, ownership, boundary, context-field, recovery, observability, and assurance metadata for the Testing, Simulation & Conformance phase.

Every quality claim is backed by reproducible, versioned evidence; test depth and coverage targets are driven by a documented risk model; tests and evidence trace to registered ARCH-034 contracts, requirements, and risks. Tests run in isolated ARCH-036 sandboxes with only synthetic data and no production reach; production AI evaluation, learning, and promotion remain owned by ARCH-029 and are never performed here; simulated and generated results are always distinguishable from production truth; and AI assistance may propose tests or fixes but never silently executes a gate or promotes from test results.
