# ARCH-024-07 Bundles, Packages, and Eligibility

`BundlesPackagesEligibilityDescriptor` exposes compositional offering semantics for bundle definitions, component cardinality, compatibility and substitutions, eligibility references, lifecycle, and governed publication.

Validation requires acyclic composition, pinned versions, deterministic compatibility and eligibility, separated pricing, fulfillment feasibility, tenant-scoped projections, safe unavailable-dependency behavior, and deterministic AI validation. Cycles, unpinned components, price-based authorization, projection authority, fabricated eligibility, shared tables, and distributed transactions are rejected.
