# ARCH-024-08 Integration, APIs, Events, and Extensions

`IntegrationApisEventsExtensionsDescriptor` exposes catalog API and event, resource reference, import/export, external adapter, and extension mediation contracts.

Validation requires versioned owning-service contracts, idempotency, tenant/property scope, provenance, reconciliation, bounded rate/outage handling, least-privilege adapters, non-authoritative projections, and deterministic AI validation. It rejects extension authority, unbounded retries, unreconciled external state, fabricated results, shared tables, and distributed transactions.
