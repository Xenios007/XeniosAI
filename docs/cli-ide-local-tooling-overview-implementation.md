# ARCH-035-01 CLI, IDE & Local Tooling Overview

Executable resource-type, persona, boundary, quality-attribute, capability, context-field, data-control, recovery, observability, and assurance metadata for the CLI, IDE & Local Tooling phase.

Local developer tools are reproducible, inspectable, least-privilege, automation-safe, and compatible with registered platform contracts. Every operation resolves actor, organization, project, environment, tenant, purpose, capability, version, and correlation context; generated artifacts identify their source contracts and generator versions and are always distinguishable from production truth; production databases, secrets, and customer records are never reachable from a developer context; and AI assistance may propose commands or fixes but never silently executes or promotes them.
