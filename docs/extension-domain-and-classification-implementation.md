# ARCH-019-02 Extension Domain and Classification

`ExtensionDomainClassificationDescriptor` exposes immutable metadata for domain principles, core aggregates, supporting entities, package coordinate fields, extension contribution classes, publisher classifications, risk classification levels, extension-point categories, extension-point ownership responsibilities, composition models, authority validation checks, installation scope options, extension-owned data fields, dependency types, relationship model items, domain events, domain invariants, service boundaries, failure boundaries, governance ownership objects, and architectural rules.

Profile validation requires stable cross-version extension identity, immutable package versions, listings separate from registry identity, scoped installation aggregates, grants distinct from manifest requests, attributable executions, domain-authoritative extension-point owners, capability-driven risk classification, preserved history, exact-digest installation locking, declared (never silent) dependencies, minimal-metadata domain events, restricted platform-wide capabilities, reviewed ownership transfer, prohibited undefined composition ordering, and contained extension failure. It rejects implicit access from relationships, publisher access to tenant data without a declared processor relationship, automatic tenant-wide data exposure, implicit installation of dependent extensions, listings determining runtime state, extensions owning data outside declared bounds, handle possession as authorization, cross-service database reads, revoked packages starting executions, and first-party control waivers.

The module separates what an extension is, how it is packaged, how it is presented, where it is installed, what it may do, and how it executes — preventing marketplace, publisher, package, and installation states from becoming accidental authority.
