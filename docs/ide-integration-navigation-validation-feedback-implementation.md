# ARCH-035-08 IDE Integration, Navigation, Validation & Feedback

Executable editor-integration, language-service, registry-navigation, inline-validation, diagnostic, task-integration, secure-action, recovery, observability, and assurance metadata for the CLI, IDE & Local Tooling phase.

Editor features resolve the same fully specified actor, project, environment, and profile context as the CLI, with no implicit production. Inline validation is contract- and schema-driven and names its rule source; opening a registry record never implies permission to invoke or change it. Privileged, destructive, and external editor actions require authentication and explicit confirmation; extensions run sandboxed with declared minimal permissions; source code, secrets, and customer data never leave the editor in telemetry; and AI-proposed edits and actions apply only on explicit user acceptance.
