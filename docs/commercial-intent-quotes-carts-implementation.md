# ARCH-025-02 Commercial Intent, Quotes, and Carts

`CommercialIntentQuotesCartsDescriptor` exposes commercial intent, quote validity, cart ownership and composition, recalculation, confirmation, and authoritative conversion metadata.

Validation requires expiry enforcement, stale-quote recalculation, explicit confirmation, pinned versions, idempotency, auditable history, and authoritative commitment commands. It rejects expired quote confirmation, generated confirmation, unapproved conversion, shared databases, and local pricing/payment authority.
